# 日语学习小程序（对标百词斩）— 工程实施清单（Engineering List v1.0）

> **定位**：日语每日打卡 + 积分积累 + 同桌社交 PK，目的把"坚持学"游戏化。首发日语（N5），后续可扩其他语种。
> **形态**：微信教育类小程序（规避游戏版号）；后端微信云开发 CloudBase，小团队零运维。
> **已确认决策（用户 2026-10-19）**：
> 1. **主体 = 个人**（免费上线可行；但⚠️ 开不了微信支付、部分教育类目受限 → 收费/完整类目需在 M4 升级个体户/公司）。
> 2. **MVP 范围 = 单机打卡闭环优先**（学习+打卡+积分+streak），同桌社交放 M2、PK 放 M3。
> 3. **PK 形态 = 异步 PK**（双方各做同难度题包比正确率/用时，无需实时通信）。

## 0. 工程总览

### 0.1 技术栈
| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 微信小程序原生（WXML/WXSS/JS 或 TS） | 不引跨端框架，审核最顺 |
| 后端 | 微信云开发 CloudBase | 云数据库 + 云函数 + 云存储 |
| 登录 | `wx.login` + 云函数换 openid | 无自有账号体系 |
| 发音 | **预录音频优先** + 腾讯云 TTS 兜底 | 小程序无 Web Speech API；同声传译插件日语支持不确定 |
| 推送 | 微信订阅消息（断更提醒/同桌互动） | 需用户授权，一次性订阅 |
| 支付 | 微信支付（**M4 才接，需升级个体户/公司主体**） | 个人主体阶段不可收费 |
| 状态 | `app.globalData` + 轻量 `store` 模块 | 不引第三方状态库 |

## 2. 工程 List（逐条实现）

每条格式：**编号 · 标题** / 做什么 / 验收标准 / 依赖 / 产出

### M0 立项准备

**M0-1 · 个人小程序账号与类目确认**
- 做什么：注册个人小程序账号（mp.weixin.qq.com）；在后台确认**个人主体可选类目**（重点核对"教育"相关子类是否对个人开放，若被限制，记录需升级个体户才能选的类目）；拿到 AppID。
- 验收：后台显示账号可用、拿到 AppID；输出「个人主体可选类目清单 + 受限项」。
- 依赖：无。
- 产出：`AppID`、`类目核对.md`。

**M0-2 · 云开发环境开通**
- 做什么：开通云开发，建环境（如 `env-prod`）；记录环境 ID。
- 验收：云开发控制台可见环境；可新建集合。
- 依赖：M0-1。
- 产出：环境 ID，写入 `app.js` 的 `wx.cloud.init`。

**M0-3 · 词库与发音方案定稿**
- 做什么：确定 N5 词库来源（自研 / 采购正版，禁抓竞品词库）；确定发音为**预录音频**（采购词库常附音频）或腾讯云 TTS 兜底；产出 `words` 字段规范（wordId/假名/汉字/释义/例句/音频URL/难度）。
- 验收：N5 词清单≥600 词且来源合法；发音方案有落地路径（音频已采购或 TTS 已测通）。
- 依赖：无（可并行）。
- 产出：`词库规范.md`、`assets/audio` 占位或 TTS 接入验证。

**M0-4 · 工程脚手架初始化**
- 做什么：初始化小程序 + 云开发；建立 0.2 目录骨架；`app.json` 注册路由；`app.js` 初始化云开发。
- 验收：开发者工具可预览空白壳；路由无报错。
- 依赖：M0-1, M0-2。
- 产出：`project.config.json`、`app.js/json/wxss`、空页面。

### M1 MVP 单机闭环

**M1-1 · 数据模型建表**
- 做什么：建 0.3 全部集合；写种子数据（`wordbooks` N5；`words` 首包；`dailyTasks` 默认模板「20 词/天」；`achievements` 基础项）。
- 验收：集合存在且有种子数据；云函数可读取。
- 依赖：M0-2, M0-3。
- 产出：集合 + 种子导入脚本。

**M1-2 · 登录**
- 做什么：云函数 `login`（`wx.login`→openid，落 `users`）；`launch` 页进入；首次建档 `profiles`（等级/设置）。
- 验收：打开能登录；首页显示积分与连续天数初始值。
- 依赖：M0-4, M1-1。
- 产出：`cloudfunctions/login`、`pages/launch`、`utils/store.js`。

**M1-3 · 学习主页**
- 做什么：`home` 渲染今日任务条（`daily-task-bar`）、积分计数器（`point-counter`）、连续天数（`streak-bar`）、进入背词/复习入口。
- 验收：主页展示三项数据 + 入口；点击可跳转。
- 依赖：M1-2。
- 产出：`pages/home` + 组件。

**M1-4 · 背单词模块（核心）**
- 做什么：`learn` 从 `words` 取当日词包；`audio.js` 播放发音；三种题型（看词选义/听音选义/看义拼写）；点错只提示「再听一次」（零失败，低挫折）；完成调用 `completeStudy` + `addPoints` + 写 `userWords` 初始熟练度。
- 验收：发音正常；点错无惩罚；完成发放积分；熟练度写入。
- 依赖：M1-1, M1-3, M0-3（音频）。
- 产出：`pages/learn`、`utils/audio.js`、`cloudfunctions/completeStudy`、`addPoints`。

**M1-5 · SM-2 复习调度**
- 做什么：`utils/srs.js` 实现简化 SM-2；`review` 按 `userWords.nextReview` 拉待复习词；答对升熟练度、推后复习，答错提前。
- 验收：复习词按算法出现；熟练度随时间推进。
- 依赖：M1-4。
- 产出：`pages/review`、`utils/srs.js`。

**M1-6 · 每日任务 + 打卡**
- 做什么：云函数 `getDailyTask` 下发当日任务；完成状态写 `dailyTasks`；首页任务条实时刷新；首次完成即打卡。
- 验收：每天生成任务；完成划项；跨天重置。
- 依赖：M1-1, M1-4, M1-5。
- 产出：`cloudfunctions/getDailyTask`、`daily-task-bar` 联动。

**M1-7 · 积分账本 + 连续天数 streak**
- 做什么：`pointsLedger` 记录每笔积分（防作弊可追溯）；`streaks` 记录连续天数，每日首完成 +1，断签清零；连续里程碑额外加分。
- 验收：积分变动可追溯；断签连续清零；连续天数展示首页。
- 依赖：M1-4, M1-6。
- 产出：账本逻辑 + `updateStreak` 云函数。

**M1-8 · 我的/成就**
- 做什么：`profile` 展示积分账本、连续日历、成就墙（`achOwned`）；达成条件触发解锁弹窗。
- 验收：能看到积分明细、连续天数、已得成就。
- 依赖：M1-7。
- 产出：`pages/profile`、成就逻辑。

**M1-9 · 发音能力正式接入**
- 做什么：`audio.js` 封装发音（预录音频优先，失败回退 TTS）；网络异常兜底。
- 验收：所有发音点音质正常、延迟可接受。
- 依赖：M0-3。
- 产出：`utils/audio.js` 终版。

> ✅ **M1 完成标志**：用户能登录→看到今日任务→背词/复习（听音+三题型）→积分增长→连续天数累计，全链路真机跑通，且**个人主体可提交审核上线**。

## 3. 实现顺序建议

1. **M0-1 ~ M0-4**（占坑：账号/环境/词库发音/脚手架），多可并行。
2. **M1-1 → M1-2 → M1-3 → M1-4 → M1-6 → M1-7**：先让「登录→任务→背词→积分→连续」最小跑通，立刻真机试。
3. 补 **M1-5 → M1-8 → M1-9** 完成单机闭环，此时即可**个人主体提交审核上线**（免费版）。
4. **M2（同桌）→ M3（异步 PK）** 做社交留存。
5. 确定要收费时走 **M4-0 → M4-1 → M4-2 → M4-3** 升级主体并商业化。

## 4. 风险与注意
- **个人主体限制**：M0–M3 免费、无支付、类目可能受限；收费必须 M4 升级个体户/公司（提前规划，避免返工）。
- **类目审核**：教育类目对个人/企业要求不同，M0-1 务必在后台实测可选类目，避免 M1 做完发现发不出。
- **版权**：词库/音频必须正版或自研，禁抓百词斩等竞品；日语内容为原创无 IP 问题。
- **内容安全**：同桌/PK 的 UGC 必须接审核（M2-4），否则上线会被打回。
- **发音**：日语 TTS 先测可用性与音质，优先预录音频保体验与离线。
- **儿童隐私**：若后续面向未成年人，遵守小程序儿童隐私规范，最小化收集。
- **审核红线**：不可诱导分享、不可"分享才能继续"、不可虚假打卡。

## 5. 本版（单机 MVP）开发运行说明

### 5.1 准备开发账号（关键）
- 注册**免费个人小程序账号**（mp.weixin.qq.com），拿到 AppID。
- ⚠️ 不要用"测试号"：测试号不支持插件与云开发，会导致同声传译发音与云函数无法使用。
- 在 mp 后台「设置 → 第三方设置 → 插件」中添加 **微信同声传译**（provider: `wx069ba97219f66d99`）。
- 微信开发者工具中「开通云开发」创建环境，复制**环境 ID** 填入 `miniprogram/app.js` 的 `globalData.env`。
- 源码位置：`jp-miniprogram/`（miniprogram 前端 + cloudfunctions 云函数）。

### 5.2 本地运行
1. 微信开发者工具导入项目，目录选 `jp-miniprogram/`，AppID 填你的个人账号 AppID。
2. 右键 `cloudfunctions/login`、`getDailyTask`、`completeStudy`、`getProgress` 分别「上传并部署：云端安装依赖」。
3. 云开发控制台建集合：`users` `userWords` `streaks` `pointsLedger` `dailyLogs`（权限默认，由云函数读写）。
4. 编译预览，点「开始学习」即可跑通：登录 → 今日任务 → 背词(听音+选义) → 积分 → 连续天数 → 日历记录。

### 5.3 本版已实现范围（对齐本次收窄需求）
- 单机学习闭环（登录 / 每日任务 / 背词 / 积分 / 连续天数 streak）
- **学习日历 + 每日学习记录**（云端持久化，换机/清缓存可用同一账号恢复）
- 日语发音：**微信同声传译插件**实时合成（以假名发音，规避汉字误读）
- N5 词库 90 词，儿童零基础友好（数字/颜色/家人/动物/食物/身体/动词/形容词/学校/时间）

- 暂未做：同桌社交、PK、商城/会员（按之前约定放后续里程碑）

### 5.4 后续接入个体户/公司（收费时）
