# 本地音频命名规则（audio.js 回退播放用）

把日语发音 mp3 放进本目录，文件名 = 页面上显示的日语文字（含标点/空格），扩展名 .mp3。

- 五十音图：平假名  →  あ.mp3 / か.mp3 / が.mp3(浊音) / ぱ.mp3(半浊音) / きゃ.mp3(拗音)
- N5 单词：words.js 的 kana 字段  →  りんご.mp3 / ほん.mp3
- 常用语：整句日文  →  こんにちは。.mp3

获取方式见 README「本地音频发音」章节（在线 TTS / 录屏 / 真人录音）。
插件可用时（正式小程序+后台加 WechatSI+app.json 声明 plugins）会自动优先用插件合成，本目录可留空。
